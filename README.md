## 🇬🇧 English Version

A lightweight companion for Elite Dangerous to track your "Road to Riches" route in real-time. The tool automatically detects scanned planets, marks them as done, and plays an optional notification sound.

### ✨ Features

- **Real-time Tracking:** Monitors journal logs and checks off bodies instantly.
- **Audio Feedback:** Optional sound upon successful scan.
- **Cross-Platform:** Native builds for Windows and Linux (Fedora, Arch, Ubuntu).
- **Standalone:** No installation required. Icons and sounds are embedded.

### 🛠 Installation

1. Download the latest binary from [Releases](../../releases).
2. **Windows:** Run `road-to-riches-windows.exe`.
3. **Linux:** Run `chmod +x road-to-riches-linux` and start it with `./road-to-riches-linux`.

## 🇩🇪 Deutsche Version

Ein leichtgewichtiger Begleiter für Elite Dangerous, um deine "Road to Riches" Route in Echtzeit zu verfolgen. Das Tool erkennt automatisch gescannte Planeten, markiert sie als erledigt und spielt optional einen Bestätigungssound ab.

### ✨ Features

- **Echtzeit-Tracking:** Überwacht die Journal-Logs und hakt Planeten sofort ab.
- **Akustisches Feedback:** Optionaler Sound bei erfolgreichem Scan.
- **Plattformübergreifend:** Native Builds für Windows und Linux (Fedora, Arch, Ubuntu).
- **Standalone:** Keine Installation nötig. Icons und Sounds sind in die Datei eingebettet.

### 🛠 Installation

1. Lade die aktuelle Version unter [Releases](../../releases) herunter.
2. **Windows:** Starte die `road-to-riches-windows.exe`.
3. **Linux:** Mache die Datei mit `chmod +x road-to-riches-linux` ausführbar und starte sie.

## ⚙️ Log Paths / Log-Pfade (Fedora, Linux & Flatpak)

**English:** If you use Steam as a Flatpak on Fedora, your logs are likely located in the Flatpak container.
**Deutsch:** Wenn du Steam als Flatpak unter Fedora nutzt, liegen deine Logs wahrscheinlich im Flatpak-Container.

- **Standard (Linux):** `~/.local/share/Steam/steamapps/compatdata/359320/pfx/drive_c/users/steamuser/Saved Games/Frontier Developments/Elite Dangerous/`
- **Flatpak Path:** `~/.var/app/com.valvesoftware.Steam/.rocket/dragon/Logs/`

> *Note for Fedora users:* Just like the FS-UAE Flatpak (ID `net.fsuae.FS-UAE`) stores data in `~/.var/app/`, Elite logs in Flatpak follow a similar structure.
